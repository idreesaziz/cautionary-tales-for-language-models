# Cautionary Tales for Language Models

**[Read the report (PDF)](https://github.com/idreesaziz/cautionary-tales-for-language-models/releases/latest/download/Cautionary_Tales_for_Language_Models.pdf)**

The report studies how error accounts and their endings change abstention across
Qwen, Llama, and Ministral. It separates forced-choice accuracy, confidence, and
the decision to answer. The [manuscript](v2/manuscript.md) and
[build source](v2/README.md) live in `paper/v2/`.

The build writes:

`output/pdf/cautionary_tales/Cautionary_Tales_for_Language_Models.pdf`

The expanded Markdown, figures, numerical checks and visual-review record share
that directory. References and the required Limitations and Dual-Use / Ethical
Considerations appendix follow the main report. Appendix B and the
[project README](../README.md#sprint-provenance-preexisting-and-new-work) identify
preexisting code and sprint additions.

The build uses the official template's fonts, page geometry, and section structure.
Dated [GitHub releases](https://github.com/idreesaziz/cautionary-tales-for-language-models/releases)
preserve previous public PDFs and source packages. The author controls submission
through Apart's official form.
